# 🏃 Drop Rush — Nude Project

Juego educativo multijugador para el aula, basado en el caso de estudio **Nude Project** (materia Comercialización, Licenciatura en Administración).

Cada grupo corre desde el celular hacia el drop limitado de Nude Project, esquivando obstáculos estilo Subway Surfers y atravesando el arco de la respuesta correcta. El proyector muestra la pregunta, el mapa de la carrera y las posiciones en vivo.
