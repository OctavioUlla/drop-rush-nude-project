# 🏃 Drop Rush — Nude Project

Juego educativo multijugador para el aula, basado en el caso de estudio **Nude Project** (materia Comercialización, Licenciatura en Administración).

Hasta 40 grupos (un celular por grupo) corren en un runner 3D estilo Subway Surfers hacia el drop limitado de Nude Project, esquivando y saltando obstáculos y atravesando el arco de la respuesta correcta. El proyector muestra la pregunta, el mapa de la carrera y las posiciones en vivo.
